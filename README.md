# Codex Custom Share Patch

为 Windows Codex 增加动态背景设置、消息用量栏与按任务控制的额度恢复续做。

> **版本限制：当前仅适配 26.1013.40934 对应的官方原始资源，不兼容 26.1016 等其他版本。安装器会在复制前核验，不会强行套用旧补丁。**

## 下载

[下载分享补丁 ZIP](dist/CodexCustom-SharePatch.zip?raw=true) · [SHA-256 校验值](dist/CodexCustom-SharePatch.zip.sha256)

这个下载包只包含自定义代码、安装脚本和说明。它不包含官方程序、账号、聊天记录、个人模型配置或第三方壁纸。

## 安装

1. 准备 Windows 10/11 x64、匹配版本的官方 Codex 原始资源及 Python 3.11+。
2. 下载并完整解压补丁 ZIP，运行 Install.cmd。
3. 安装器在本机创建独立的 **Codex Custom** 副本，不覆盖官方目录；成功后会创建开始菜单入口。
4. 使用自己的账号，进入 **设置 → 外观 → 动态背景**，选择有权使用的图片或视频。

若只有较新的官方 Codex，请等待对应适配版。不要绕过版本校验。

## 功能

- 支持本地图片或视频背景，调节亮度、遮罩、壁纸不透明度、输入框透明度和毛玻璃模糊；重启后保留。
- 回复底部显示 Tokens、Context left、5-hours、Weekly，数据缺失时显示 --。
- 每个任务标题栏独立 **Auto-resume** 开关，默认关闭。启用的任务因明确额度错误停止后，额度恢复时继续原任务。Codex 需保持运行；扩展不批准权限请求、不切换模型、不消耗额度重置券。

## 目录

- bundle/：可直接使用的补丁安装目录；从源码运行时执行 bundle/Install.cmd。
- bundle/payload/：背景设置、用量栏、自动续做和版本适配源码。
- dist/：准备好的分享 ZIP 与 SHA-256 校验值。

[完整安装与数据说明](bundle/README.md)

## 说明

这是第三方本地定制补丁，不是官方发行版，不会随 Microsoft Store 自动升级。修改后原 EXE 的官方数字签名不再有效；补丁不关闭系统安全功能，也不禁用 ASAR 内容校验。

界面资料使用接收者本机的独立 UserData；后端账号、配置和任务仍使用接收者自己的 .codex 主目录。不要把任何用户数据目录、登录信息或个人壁纸加入仓库。

可以随时退出定制版并从官方入口使用原版。
