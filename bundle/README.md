# Codex Custom 本地补丁包

把这个补丁 ZIP 发给对方即可。**完整解压后运行 `Install.cmd`，不要从 ZIP 预览里直接启动。**

此包只包含自定义代码与安装脚本，不包含官方程序、发送者的账号和聊天数据，也不附带第三方壁纸。对方先安装官方 Codex，补丁在对方电脑上制作独立副本，对方使用自己的账号。

## 安装前需要

- Windows 10/11 x64，已通过官方渠道安装 Microsoft Store Codex。
- **当前补丁仅适配 Codex 26.1013.40934 对应的原始应用资源**。补丁在复制前校验原始资源；新版本不会强行套用旧补丁。如果对方只有较新的官方版本，需等待对应适配版，不能直接使用本包。
- Python 3.11 或更高版本。安装器会检查 `py -3`、`python` 和 `python3`；未找到时会提示先安装，不会自动下载程序。
- 完整的补丁目录，其中应有 `Install.cmd`、`Install.ps1` 和 `payload/`。

## 安装和使用

1. 先完全退出本机已运行的 **Codex Custom**。安装器不会强制关闭任务。
2. 双击 `Install.cmd`。不需要管理员权限，也不要“以管理员身份运行”。
3. 安装器从官方应用的安装目录复制程序文件，在 `%LOCALAPPDATA%\CodexCustom\26.1013.40934-时间-随机编号` 创建新副本并应用补丁。
4. 验证通过后创建开始菜单入口 **Codex Custom** 并打开窗口。后续使用此入口。
5. 按官方界面完成自己的登录（本机已有授权时可能复用本机授权），然后到 **设置 → 外观 → 动态背景** 选择有权使用的图片或视频。

已有副本不会被覆盖，官方安装目录不会被修改。补丁默认不强制语言、不携带网络修复或个人模型提供方设置。

若无法自动发现官方应用，可在 PowerShell 中指定路径：

```powershell
.\Install.ps1 -SourceApp "C:\Program Files\WindowsApps\OpenAI.Codex_对应版本\app"
```

`-NoLaunch` 参数可只安装、不自动打开窗口。脚本没有自动调整 PowerShell 执行策略的逻辑；若系统策略阻止脚本运行，请按本机管理要求处理。

## 数据放在哪里

- **安装来源**：只读取官方应用的程序安装目录，不读取或复制发送者的用户资料、认证文件、聊天和环境变量。
- **定制程序**：位于当前用户的 `%LOCALAPPDATA%\CodexCustom\`，不会覆盖原版。
- **界面资料与导入壁纸**：使用此电脑上的 `%LOCALAPPDATA%\CodexCustom\UserData`，与官方应用默认的 Electron 界面资料目录分开。
- **Codex 后端的账号、配置与任务历史**：仍使用此电脑当前用户的默认 Codex 主目录（通常为 `%USERPROFILE%\.codex`）。因此同一电脑上的官方版和定制版可能共享这部分本机数据。补丁包本身不包含该目录，也不把发送者的数据搬到对方电脑。

## 功能

- 在外观设置中选择本机图片或视频，调整亮度、遮罩、透明度和毛玻璃。
- 消息底部用量栏。
- 任务标题栏独立 **Auto-resume** 开关，默认关闭；开启的任务因明确的额度耗尽停止时，额度恢复后继续原任务。Codex 需要保持运行。

## 分享、更新与恢复

分享的是这个补丁包，不是你正在使用的整个应用文件夹；不要把 `UserData`、`.codex`、登录信息、私钥或个人配置加入 ZIP。壁纸请由对方自己选择有权使用的文件。

这是第三方本地定制副本，不是官方发行版。修改后原 EXE 的官方数字签名不再有效；安装器不会关闭系统安全功能或禁用 ASAR 内容校验。定制副本不会跟随 Microsoft Store 自动升级，新版需要新的适配补丁。

要返回官方版，完全退出 Codex Custom，再从官方入口打开 Codex。不要删除本机 `.codex` 目录。

安装失败时窗口会说明原因，并保留 `install-error-*.log`。失败不会切换开始菜单快捷方式；新建但失败的副本保留在目标目录便于诊断，不会自动删除任何旧安装。
